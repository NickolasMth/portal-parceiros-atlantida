# Perguntas RBS

| ID | Tema | Pergunta / decisão |
| --- | --- | --- |
| PQ01 | IA | Existe interesse ou abertura para utilização de IA? Em caso positivo, existe caso de uso prioritário e qual dor sentem mais necessidade? |
| PQ02 | Integrações | Existe interação entre os ecossistemas/sistemas da RBS que precisam se comunicar com o portal? |
| PQ03 | Atendimento | Quais canais os parceiros utilizam para tirar dúvidas ou solicitar suporte? |
| PQ04 | Comunicação | Existe interesse em centralizar e automatizar a comunicação entre RBS e parceiros? |
| PQ05 | Usuários | Quem irá cadastrar os funcionários do patrocinador: RBS, próprio patrocinador ou ambos? |
| PQ06 | Permissões | Quais níveis de acesso devem existir dentro do patrocinador e dentro da RBS? |
| PQ07 | Feedback | O que a RBS precisa obter da pesquisa pós-evento e como pretende utilizar esses dados e quais as principais métricas? O patrocinador terá acesso também? |
| PQ08 | Métricas | Quais indicadores serão usados pela RBS para considerar o portal bem-sucedido? |
| PQ09 | Negócio | A quantidade de cortesias é definida individualmente para cada patrocinador ou existe uma regra fixa por nível de cota? |
| PQ10 | Negócio | O patrocinador apenas consulta suas cortesias ou precisa realizar alguma ação dentro do portal? Se sim, quais? |
| PQ11 | Negócio | Os tipos de cortesia disponíveis também variam conforme a cota? Se sim, quais as variações por cota? |
| PQ12 | Negócio | A RBS precisa acompanhar quem já destinou e quem ainda não destinou? |
