# Portal do Patrocinador — Planeta Atlântida 2027

## Sobre o projeto

Solução desenvolvida no Desafio GC 2026, proposto pelo Grupo RBS,
com o objetivo de centralizar a jornada dos patrocinadores do
Planeta Atlântida 2027.

## Objetivo

Criar um portal de acesso restrito que permita aos patrocinadores
consultar e acompanhar informações da parceria, entregas, documentos,
status, benefícios, prazos e histórico.

## Problema

Atualmente, informações relacionadas à parceria podem estar
distribuídas entre diferentes fluxos e canais, dificultando o
acompanhamento das entregas, informações e resultados.

## Usuários

- Administrador RBS
- Patrocinador
- Usuários vinculados ao patrocinador

## Principais módulos

- Dashboard
- Informações da parceria
- Entregas
- Documentos
- Mídias e comprovações
- Credenciamento e benefícios
- Pesquisa
- Relatórios
